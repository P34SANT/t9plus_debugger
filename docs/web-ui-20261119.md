retained their process IDs/start times. No target reset, firmware flash,
FPGA reload, USB/IP detach or Windows reconnect was performed.

- Base probe release: `/opt/plink/releases/2df243f00215eab8` (unchanged).
- Web package: `/opt/plink/web-releases/fec6873ff1facac7`.
- Active link: `/opt/plink/web-current`.
- Package manifest SHA-256:
  `fec6873ff1facac7e5272a00f16b6f2aa89ff8cd3b7087dfb5e187e53da60e1e`.
- Override: `/etc/systemd/system/t9-io-daemon.service.d/60-plink-web.conf`.
- `ExecStartPre` verifies package hashes and the base probe manifest.

The web package contains the daemon, request validation, ownership helper, pin
configuration, canonical pin map and three web assets. It lives separately so
the previously verified FPGA/probe release is not edited or relabeled.
The package and one-time installer are retained in board staging under
`/home/xilinx/staging/plink-web-package-20261119-1` and
`/home/xilinx/staging/plink-install-web-20261119.sh`.

To restore the previous web service only:

```sh
sudo systemctl stop t9-io-daemon
sudo rm /etc/systemd/system/t9-io-daemon.service.d/60-plink-web.conf
sudo systemctl daemon-reload
sudo systemctl start t9-io-daemon
```

This rollback restores the former interface and its token requirement.
Keep the web package preserved for inspection. Do not restart FPGA/probe
services or reset a USB hub to update or restore the web interface.
